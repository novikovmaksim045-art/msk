MSK Zebra Label Studio v1.2

Главное изменение: строгая очередь печати без случайных повторов.

1. Для каждой партии вычисляется уникальный SHA-256 по всем кодам в исходном порядке.
2. Состояние печати хранится в %LOCALAPPDATA%\MSK\Zebra Label Studio\journals.
3. Кнопка «Печать всех» отправляет только коды, которые еще не подтверждены как переданные в очередь Zebra.
4. PrinterWorker подтверждает каждый код отдельно после успешного WritePrinter и сразу записывает индекс в постоянный progress-журнал партии.
5. При обрыве, закрытии GUI или перезапуске ПК после повторного открытия той же партии программа продолжает с неподтвержденных кодов.
6. «Печать 1» блокирует случайную повторную печать уже подтвержденного кода.
7. Для намеренной перепечатки используйте «Перепечатать последние N».
8. Перепечатка берет последние N кодов из фактической истории подтвержденной очереди и печатает их в том же порядке. Основная очередь назад не сдвигается.
9. Журналы партии сохраняются при обновлении программы.

Важно: подтверждение означает, что Windows RAW spooler успешно принял ZPL конкретной этикетки. Физическое прохождение этикетки через принтер без двустороннего опроса конкретной модели Zebra программно гарантировать нельзя.
