MSK Zebra Label Studio v1.4

Изменение v1.4:
- Добавлена кнопка «Найти Zebra».
- Поиск принтеров выполняется отдельным PrinterFinder.exe, а не в GUI.
- Если Windows spooler/драйвер зависает, поиск прерывается через 8 секунд; основное окно остается рабочим.
- Zebra/ZDesigner подставляется автоматически при обнаружении.
- Если найдено несколько Zebra/ZDesigner, выбирается первая и показывается список.
- Поиск не выполняется при запуске программы, поэтому старт остается быстрым и работает даже на ПК без Zebra.

Сохранены функции v1.2:
- защита от повторной печати уже подтвержденных кодов;
- продолжение партии после перезапуска;
- «Перепечатать последние N» без отката основной очереди;
- отдельные процессы PDFDecoder и PrinterWorker;
- CSV/PDF и макет работают без подключенного принтера;
- GS1 DataMatrix/FNC1/ASCII 29 GS сохраняются.


Изменение v1.4: поле принтера стало выпадающим ComboBox. Кнопка «Найти Zebra» заполняет список всеми найденными Zebra/ZDesigner; пользователь выбирает нужную очередь. Поле остается редактируемым для ручного ввода имени очереди.
