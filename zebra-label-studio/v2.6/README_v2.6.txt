MSK Zebra Label Studio v2.6

Изменения стабильности:
- новый редактор текста на Windows Forms (PowerShell/.NET), без собственного Win32 EDIT;
- явный индикатор: 1 строка / 2 строки;
- в главном окне текст отображается как предпросмотр, редактирование через одну кнопку;
- кнопка «Диагностика» открывает папку логов;
- watchdog сохраняет hang-*.log со стеками всех goroutine, если UI не отвечает более 5 секунд;
- panic сохраняется в crash-*.log;
- основной журнал событий: logs/app.log;
- журналы диагностики сохраняются при обновлении программы.

Если программа зависла: подождите 6-10 секунд, затем завершите её через Диспетчер задач. После запуска нажмите «Диагностика» и передайте последние app.log и hang-*.log.
